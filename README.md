A neon arcade game about colour and nerve: fly down three light lanes, hop between them, and shift your ship's prism colour to match each gate. A gate of another colour breaks your hull. Chain gates for a multiplier, catch crystals for points, and see how far the drift takes you. Plain canvas and ES modules, no library, no network, plays offline.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 — ↑ ↓ hop lanes, 1 2 3 shift prism, P pause.
